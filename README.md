InternHub — Career Match Finder

A smart, interactive dashboard to discover internships and find career opportunities that match your skills.

InternHub helps students explore internship opportunities, identify relevant roles, save interesting listings, and manage their application progress in one place.

✨ Features

- 🔍 Smart Internship Search — Search internships by keywords.
- 🎯 Skill-Based Matching — View match scores based on selected skills.
- 🔖 Save Internships — Save interesting opportunities for later.
- 📋 Application Tracker — Track your internship application statuses.
- 🎛️ Filters and Sorting — Find relevant internships more easily.
- 💡 Career Insights — Explore insights based on your selected skills.
- 🌙 Dark Mode — Switch between dashboard themes.
- 💾 Local Storage — Keep supported preferences and saved information in your browser.
- 📱 Responsive Design — Designed for desktop and mobile screens.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
